# Лабораторная работа. Многопоточность и асинхронность в Go

## Замеры

Go 1.24.4, Linux amd64. Три запуска `go run .`. Время в секундах. За медиану взят средний по величине замер из трёх.

| Режим | Замер 1 | Замер 2 | Замер 3 | Медиана | Результат |
| --- | ---: | ---: | ---: | ---: | --- |
| Последовательно | 1,604 | 1,603 | 1,603 | 1,603 | 8 результатов, сумма 204 |
| Пул из 1 обработчика | 1,604 | 1,605 | 1,605 | 1,605 | 8 результатов, сумма 204 |
| Пул из 4 обработчиков | 0,404 | 0,401 | 0,401 | 0,401 | 8 результатов, сумма 204 |
| Пул из 4 обработчиков, таймаут 300 мс | 0,301 | 0,300 | 0,302 | 0,301 | Результатов по запускам — 4, 4, 4, ошибка таймаута |

Ускорение рассчитано как медиана последовательной обработки, делённая на медиану времени пула. Для одного обработчика — **1.00×**, для четырёх — **4.00×**.

## Тесты

```text
$ go test -timeout 15s ./...
ok  	lab/concurrency	0.405s
$ go test -race -timeout 30s ./...
ok  	lab/concurrency	1.414s
```

## Вывод

Один обработчик ждёт по 200 мс для каждого из восьми заданий. Четыре обработчика ждут одновременно, поэтому хватает двух раундов по 200 мс. Это работает и на одном ядре, поскольку во время ожидания таймера горутины не занимают процессор. При таймауте 300 мс первый раунд успевает завершиться, а второй прерывается.

Канал `jobs` закрывает горутина, которая отправляет задания. Канал `results` закрывает отдельная горутина после завершения всех воркеров и отправителя. Так сборщик выходит из цикла по каналу после последнего результата.

## Контрольные вопросы

1. Горутина — задача, которой управляет планировщик Go. Он распределяет горутины по потокам операционной системы.
2. Да. На одном ядре ожидания таймеров могут идти одновременно, пока планировщик переключает готовые к работе горутины.
3. После завершения всех отправителей канал можно закрыть безопасно. Если закрыть его раньше, попытка отправки приведёт к панике.
4. Если получатель уйдёт и отправка невозможна, воркер заблокируется. В этой программе отправка находится в `select`, поэтому отмена контекста позволяет воркеру выйти.
